请分别判断：本段是否记载了督促整改动作、复查动作？每项填1、0，或待核。

督促：如责令、要求整改、限期整改、约谈、督办。

复查：如复查、回头看、验收、销号。

1表示本段有肯定性的动作记载；0表示本段未提供这样的记载。0不证明现实中没有做。

动作是否有记载，与工作效果如何，分开判断。若无法判断，可填“待核”并说明缺什么材料。
